# 去吧！皮卡丘／去吧！伊布

在宝可梦 去吧！皮卡丘与 去吧！伊布（2018）中，Pia 静态链接进 `main`（RTTI 中有 269 个 `nn::pia` 类），游戏的 C++ 代码通过 `gflnet3` 以协议缓冲消息叠在其上——一年后剑／盾使用的同一中间件。

静态阅读来自 去吧！皮卡丘 1.0.2（`010003f003a34000`，更新 NSP `v131072`，SDK 5.4.151.0）；硬件测量对照法文 去吧！皮卡丘与 去吧！伊布。去吧！伊布使用皮卡丘的本地通信 id，因此两种角色与伊布交换时无需改动。

本地交换与对战要求双方输入连接暗号：从固定十只中按顺序选三只，分两行显示：皮卡丘、伊布、妙蛙种子、小火龙、杰尼龟；波波、绿毛虫、小拉达、胖丁、地鼠。暗号设定广播的场景 id（[会话页](lgpe_session.md#the-link-code)）；任意暗号下主机与加入均可。

## 已可用

`bin/lgpe_join.py` 加入主机会话，`bin/lgpe_host.py` 托管一台主机加入的会话。一个席位可连续多笔交换：每笔交换正常存档后，交换分发器从状态 7 回到状态 1，除非存档报告连接结束（`0x886908`）；存档会在新通道上重建队伍报价对象（`0x8375a4`）（[会话页](lgpe_session.md#the-trade-dispatcher)）。两个启动器都接受记录队列，席位上每笔交换一条。游戏不检查收到的盒子结构任何字段：一只闪光 100 级、全 31 个体、全 200 AV 的冒充者百变怪会在摘要画面读回。克隆协议的接管交换通过游戏的 `0x11b080` 闸门，可靠协议承载身份、报价、提交与 kind 4（下一笔交换的选择）；`pokeldn.lgpe.pb7` 读写报价与 kind 4 携带的 232 字节盒子结构。

每笔完成条目保存为带校验和的 260 字节文件；主机在主机离开后以退出码 0 退出。由 `pokeldn.pokemon` 构建（选定等级、性别、性格、球种、个体与 AV）并以 `bin/lgpe_host.py --fresh-pid` 送出的记录，会在接收方摘要画面显示这些字段。

主机玩家按「返回」时离开席位。`bin/lgpe_join.py --leave-after SECONDS` 在首次应答的交换步骤后等待该时长再执行相同退出；`bin/lgpe_host.py` 应答主机的「返回」（[加入方离开](lgpe_session.md#a-joiner-leaving)）。`tests/test_lgpe_host_commit.py` 用脚本化主机锁定主机提交阶段：错误提交会使主机停在确认画面且存档交换锁开启（计入游玩时间十分钟内不能交换），随后进入致命错误画面。
