# 晶灿钻石与明亮珍珠

《晶灿钻石》和《明亮珍珠》是 ILCA 开发的联机游戏，其 IL2CPP 游戏代码直接运行在 Pia 上。页面内容涵盖了 1.3.0 版本在联盟房间（宝可梦中心 2F，左侧服务员，简单的“是”）和地下大洞穴中的功能。

## 状态

在零售硬件上运行时：

| 功能 | 详情 |
|---|---|
| 控制台会话中的一个席位 | 只需 `prod.keys` 和 LDN 密码即可；每个数据包都能解密；发送路径与控制台的密文字节完全匹配 |
| 传输 | 本地、Mesh 站和 Mesh 协议握手、RTT 计时器、双向可靠传输 |
| 联盟房间中的一个角色 | 可以行走、展示交易表情、运行游戏问候对话 |
| 交易 | 组装好的宝可梦被接受并保存；交易在单个关联中链式进行（[交易](bdsp_trade.md#the-completed-trade)） |
| 托管 | 控制台进入联盟房间后加入托管的房间并进行交易（[托管](bdsp_session.md#hosting)） |
| 球囊 | 组装好的囊落在玩家持有的印章中并进入收藏（[协议页面](bdsp_protocol.md)） |
| 记录混合，战斗大厅 | 最多可达控制台的记录及其六只选定的宝可梦 |
| 地下大洞穴 | 角色可以在地板上行走；控制台的秘密基地可以被读取出来 |
