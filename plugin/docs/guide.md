# 从这里开始

pokeldn 通过本地无线与 Switch 或 Switch 2 上的宝可梦游戏交换。USB 上的 ESP32 开发板充当无线电。主机本身无需安装任何东西。

## 你需要准备

- 一块经典 ESP32 开发板（ESP32-D0WD、WROOM-32E），带 USB 串口桥；或一块 ESP32-S3、ESP32-C3、ESP32-C6，通过其原生 USB 口连接。均使用 2.4 GHz。不支持 S2 开发板。Seeed Studio XIAO ESP32C3 需接上附带天线；XIAO ESP32C6 使用板载天线。
- 一根 USB 数据线。仅充电线不会出现串口。
- 从你自己的 Switch 导出的 `prod.keys`。应用只会询问一次。
- 「游戏」页上七款游戏中的任意一款。

## 首次运行

1. 开发板：插入开发板，在「无线」旁选择「安装」。应用会识别芯片、写入固件，并自行检测开发板。开发板正常应答后，页面顶部会显示「已是最新」。
2. 游戏：选择一款游戏和一个工具。「主机」类工具等待你的主机加入；「加入」类工具会找到主机自己发起的搜索。
3. 要送出的宝可梦：搜索物种并按「生成」。PKHeX 会为该游戏生成一只合法的宝可梦，训练家信息来自「设置」。
4. 「会话」面板里的「开始前」会列出仍缺的项目，并附带修复按钮。按「主机上」的步骤操作，然后按「开始」。

带两个 USB 口的 ESP32-S3、C3 或 C6，只能通过标有 USB 的那一侧与应用通信。从另一侧（COM 或 UART）刷固件可以成功，但之后开发板不会应答；「开发板」页会说明这一点。若同时插入多块开发板，「使用此开发板」可指定会话使用哪一块。

物种下方的「更多选项」可设置性格、特性、性别、携带物、球种、亲密度、个体值与努力值（去吧！系列为 AV，传说 阿尔宙斯为努力等级）。留空则随机。列表只包含该物种在该游戏中合法可用的选项；若组合被 PKHeX 判为不合法，「生成」会拒绝并给出原因。只有当「设置」里的「你的训练家」与主机上的玩家一致时，交换得到的宝可梦才会保留亲密度；火红／叶绿每次交换都会把亲密度设为 70。

宝可梦下方的「添加交换」可在一次会话中排队最多六笔；每完成一笔就会送出下一只。所有交换工具都会显示此项。每笔交换收到的宝可梦都会单独存成文件。

可以把文件拖进应用：把宝可梦文件或 Showdown 队伍（`.txt`）拖到一笔交换上可填入内容，拖到「添加交换」上则按文件各排一笔。把礼物文件拖到「礼物」卡片会打开它；把 `.bin` 拖到「开发板」页的「固件」卡片，确认后会安装。

主机送来的宝可梦保存在 `Documents/pokeldn/Received`，并会复制一份到「银行」。「银行」的加号按钮，或把文件拖到其网格上，可导入宝可梦文件或整份游戏存档：其中每只合法宝可梦都会入库一次，原文件本身不变。来自更早游戏的宝可梦会按 HOME 转入规则丢掉携带物并忘记秘传技。

## 释放存储空间

「设置」→「存储」会显示可释放多少空间。按「清理本地文件」，再按「清理文件」，可删除已保存的会话记录、日志、临时送出物和未使用的已生成宝可梦。若还要提交问题报告，请先另存需要的记录。已收到的宝可梦、当前选中的送出物、密钥、固件和设置会保留。清理前请先结束当前运行。

## 火红／叶绿的语言

神秘礼物的「主机」卡片会显示版本与自动语言检测。选择火红或叶绿。在游戏的朋友列表中选中 pokeldn 后，游戏会回报卡带代码；pokeldn 在发送代码前会据此选择对应语言的礼物脚本和 RAM 地址。两个版本均支持英语、法语、德语、意大利语、西班牙语和日语。

保存原生 `.wc3` 时，若礼物因版本或语言而不同，会询问卡带类型。`.pokegift` 会保留全部变体，并在主机连接时选用正确的那一份。

「高级」里的训练家语言描述的是 pokeldn 自己在连接上的训练家，不会选择主机的语言。

## 基础与高级

「基础」显示大多数运行需要的字段；各游戏已测过的设置会在底层自动套用。「高级」列出该游戏会话接受的全部选项，并附带各自的帮助文字。在此设置的值会覆盖「基础」字段。除非某篇指南或问题报告要求改动，否则请保持默认。

大多数玩家不必改的设置在「高级」顶部，且已设好：会话自行停止前的时限、无线信道，以及「每次运行新 PID」。「每次运行新 PID」会给每只送出的宝可梦新的 PID，以便已经收过它的存档可以再次收下；若文件的 PID 必须保持不变（例如活动宝可梦），请关掉此项。

## 使用自己的宝可梦文件

「或使用宝可梦文件」可载入从 PKHeX 导出的文件。应用会用 PKHeX 检查，并在送出前显示是否合法。不合法的宝可梦在对方绘制时可能导致对方游戏崩溃。

## 神秘礼物

每个神秘礼物工具都以四种选择开始。「使用预设」发送现成礼物。在剑／盾上，「官方活动」列出真实活动卡片（宝可梦、道具、服装、对战点数），并带搜索框。「自己制作」打开表单：在火红／叶绿上可以是带文字、交付人和内容的奇妙卡片、奇妙新闻，或你自己的 ARM 代码；在剑／盾上可以是宝可梦、蛋、道具或对战点数。「打开文件」发送他人分享的 `.pokegift`、火红／叶绿上的 `.wc3` 卡片，或剑／盾上的 `.wc8` 卡片。

「自定义」把预设变成可改的表单。「发送前」显示主机将收到什么、何时发生，以及适用于哪些卡带；若有问题会以红色显示，且「开始」保持不可用。

在火红／叶绿上，「游戏增强」可改变游戏玩法，例如加速或添加跟随宝可梦。选好增强并发送后立即生效，重启游戏后失效。若重启后还要用：勾选「稍后恢复增强」，发送增强，再发送「妈妈恢复你的增强」。每次重启后回家与真新镇的妈妈对话即可重新开启。跟随宝可梦总会被保存。再收一张奇妙卡片会替换妈妈的礼物；再次发送即可恢复她开启已存增强的能力。

「读取存档」会在会话日志中显示结果。训练家 ID（TID）是训练家卡片上的号码；秘密 ID（SID）通常隐藏。队伍读出显示上次保存队伍中的每只宝可梦，含性格、六项个体值（0–31）和努力值。这些工具不会改动你的存档和奇妙卡片。「训练家详情」和「队伍」工具还会把读出的数据副本存到「已收到」。

「主机代码」在接收礼物时于游戏内运行。「离线检查」会先在模拟主机上运行；会挂起菜单的代码会被拒绝。原生代码可以改动正在运行的游戏或其存档。请只发送你已核对来源与行为的代码。

「保存礼物文件」把当前选中的礼物存下来以便复用或分享。无需开发板即可使用。

在火红／叶绿上，「你的存档」可把整份存档从 Switch 拷到本机，或写回一份。「从 Switch 备份」不改动主机上的存档；副本会出现在「你的存档」中，以训练家命名。「把存档放到 Switch」会把所选存档写到主机自有存档旁；主机会逐段校验、载入并保存，若出错则保留旧存档。请先备份主机。恢复会等到 PKHeX 判定整支队伍合法，或你打开「仍然恢复」。

「你的存档」保存在 `Documents/pokeldn/Saves`。可改名区分、导出为 `.sav` 供模拟器或 PKHeX 使用，或用 +／拖放到卡片上添加 `.sav`。「查看并编辑」显示训练家、队伍和电脑盒子：可改名字、金钱或硬币，调整或移除队伍宝可梦，添加一只为该存档训练家生成的宝可梦，并检查盒子合法性。「另存为新存档」会把结果加在原件旁，原件不变。

## 运行失败时

- 先停止，再退出主机的搜索画面并重新搜索。多数游戏会短暂保留过期会话。
- 每次运行只改一件事。
- 「设置」→「记录每次会话」→「打开记录」可查看每次会话的录制；把最新一份附到问题报告即可。
