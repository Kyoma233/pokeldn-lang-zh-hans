# pokeldn 简体中文语言包

[pokeldn](https://github.com/Decryptu/pokeldn) 的简体中文语言包插件，翻译了全部 1705 条界面文案。宝可梦相关术语采用官方简体中文译名。

- 适用版本：pokeldn v0.39.1。在更新的版本上也能用，那些新增、还没翻译的文案会显示为英文。
- 桌面版和安卓版都能装，用官方原版 APK 就行。

## 安装

**方法一：下载文件安装**

1. 从 [Releases](https://github.com/Kyoma233/pokeldn-lang-zh-hans/releases) 下载 `.pokeplugin` 文件。
2. 打开 pokeldn，进入「插件」（Plugins），点「添加插件」（Add a plugin），选择刚下载的文件，确认后点「安装」（Install）。
3. 进入「设置」（Settings），在「应用语言」（App language）里选「简体中文」，然后重启 pokeldn。

**方法二：添加插件源（以后可以在应用里一键更新）**

1. 在「插件」页的「插件源」（Sources）里添加 `Kyoma233/pokeldn-lang-zh-hans`。
2. 在「浏览」（Browse）里找到「简体中文」，点「安装」（Install），然后按方法一的第 3 步切换语言。
